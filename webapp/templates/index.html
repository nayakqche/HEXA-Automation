👋 Get started — set the sender in 60 seconds

Anyone can run this. Just enter the Gmail account (or any SMTP provider) that should send the daily report, the recipient address, and the time you want it delivered. Everything is saved to this server only — no third-party API key, no LLM, no signup.

▸ How do I get a Gmail App Password? (1-minute walkthrough)
  1. Make sure 2-Step Verification is ON for your Google account: myaccount.google.com/security.
  2. Visit myaccount.google.com/apppasswords.
  3. Pick app = Mail, device = Other, name it "HEXA Bot", click Generate.
  4. Copy the 16-character code (spaces don't matter) and paste it into the SMTP password field below.
  5. Use your Gmail address (e.g. yourname@gmail.com) as the SMTP username.

Not using Gmail? Just enter your provider's SMTP host/port instead (Outlook = smtp-mail.outlook.com:587, Zoho = smtp.zoho.in:587, SendGrid = smtp.sendgrid.net:587, etc.).
